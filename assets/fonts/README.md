# Social icon assets

The local font subsets and SVG icons reproduce the contact icons used at
https://jiaxuanzou0714.github.io/ (retrieved 2026-10-03).

- `social-brands.woff2`: Font Awesome 7 Brands, X and LinkedIn.
- `social-solid.woff2`: Font Awesome 7 Free Solid, envelope.
- `social-academicons.woff2`: Academicons, Google Scholar.
- `../images/social/xiaohongshu.svg` and `../images/social/wechat.svg`:
  monochrome brand icons from the reference site's `assets/img/social-icons/` directory.

No remote font or icon request is needed when browsing the site.
